Digital Evidence Investigation

// FORENSIC ANALYSIS WITH AUTOPSY — DELETED FILE RECOVERY & TIMELINE RECONSTRUCTION

project_overview.md

Project Overview

This project involved a complete digital forensic investigation using Autopsy. The objective was to analyse a forensic disk image, recover deleted artefacts, extract user activity, and produce structured evidence documentation suitable for incident response and reporting.

The work was carried out during my internship at Cyber Forensics Solutions (CFSS) and focused on practical evidence handling, timeline reconstruction, and clear reporting.

Why This Project

Real-world DFIR cases require more than tool familiarity — they demand disciplined evidence handling, ability to reconstruct events from fragmented artefacts, and clear communication of findings. This project was designed to practice the full investigation workflow from image ingestion to final report.

Methodology

  1. Created a new Autopsy case and ingested the forensic image (preserving original evidence).
  2. Ran ingest modules: hash calculation, file type identification, keyword search, and web artefacts.
  3. Recovered deleted files and examined unallocated space.
  4. Built a timeline of user activity using file system timestamps, browser history, LNK files, and prefetch data.
  5. Documented findings with supporting screenshots and exported relevant artefacts.
  6. Prepared a structured investigation report with methodology, findings, and conclusions.

Key Findings & Results

  • Successfully recovered multiple deleted user files and documents.
  • Reconstructed browser activity and recent file access patterns.
  • Identified relevant timestamps that helped establish a sequence of user actions.
  • Produced a clear evidence report suitable for further investigation or presentation.

Tools & Techniques

  • Autopsy — primary forensic analysis platform
  • Hash verification (MD5 / SHA-256) for evidence integrity
  • Timeline analysis and keyword searching
  • Web artefact and registry examination (where applicable)
  • Structured documentation and evidence reporting

Challenges & Lessons Learned

  • Understanding the difference between allocated and unallocated space when recovering deleted data.
  • Importance of maintaining chain of custody and never modifying original evidence.
  • Value of combining multiple artefact sources (files, browser, timestamps) to build a coherent timeline.
  • Clear, non-technical reporting is as important as technical analysis when communicating findings.
