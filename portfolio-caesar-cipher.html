Caesar Cipher Cryptography Toolkit

project_overview.md

Project Overview

A comprehensive multi-cipher cryptography toolkit developed in Python, supporting classical and modern encryption algorithms. The toolkit provides both a Tkinter GUI desktop application and a Flask-based web interface, making it accessible for both offline and browser-based use. AES-256 encryption is integrated for high-security text and file encryption needs.

Supported Ciphers

  • Caesar Cipher — Shift-based substitution cipher with configurable key
  • Vigenère Cipher — Polyalphabetic cipher using a keyword for encryption
  • Base64 Encoding — Standard encoding/decoding for text and binary data
  • ROT13 — Special case Caesar cipher with 13-position rotation
  • Atbash Cipher — Reverse-alphabet substitution cipher
  • AES-256 — Military-grade symmetric encryption for text and files

What I Built

  • Dual-interface architecture — Tkinter GUI for desktop use and Flask web app for browser access
  • AES-256 encryption module for both plaintext strings and binary file encryption
  • Encode and decode operations for all supported ciphers in a unified interface
  • File encryption/decryption with key management for secure data handling
  • Clean modular Python codebase — each cipher implemented as a standalone module
