Metasploitable 2 VAPT Lab

project_overview.md

Project Overview

This project was a full Vulnerability Assessment and Penetration Testing (VAPT) exercise against the intentionally vulnerable Metasploitable 2 virtual machine. The objective was to practice the complete attack lifecycle in a controlled, authorized lab environment: reconnaissance, service enumeration, exploitation, privilege escalation, and structured reporting with remediation advice.

Disclaimer: All testing was performed exclusively in an isolated lab environment against Metasploitable 2. No systems outside the authorized lab were targeted.

Why This Project

Hands-on exploitation against a known vulnerable target is one of the fastest ways to internalize how common services fail and how attackers chain weaknesses. This lab reinforced methodology, tool proficiency, and the importance of clear documentation for both technical and non-technical audiences.

Methodology

  1. Reconnaissance — Host discovery and port scanning with Nmap (TCP/UDP, version detection, default scripts).
  2. Enumeration — Identified running services (FTP, SSH, HTTP, Samba, MySQL, etc.) and gathered banners / version information.
  3. Vulnerability Mapping — Matched discovered services to known public exploits and Metasploit modules.
  4. Exploitation — Successfully compromised multiple services using Metasploit and manual techniques.
  5. Privilege Escalation — Moved from low-privileged shells to root where possible.
  6. Post-Exploitation & Reporting — Collected evidence, documented each finding with severity, and recommended remediation steps.

Key Findings & Results

  • Multiple high-severity services were successfully exploited (examples: weak/default credentials, outdated software with public exploits).
  • Demonstrated clear attack paths from initial foothold to higher privileges.
  • Produced a structured report covering methodology, findings, risk ratings, and remediation recommendations.
  • Reinforced the value of thorough enumeration before jumping to exploits.

Tools & Techniques

  • Nmap — host discovery, port scanning, service/version detection
  • Metasploit Framework — exploit modules, payloads, sessions
  • searchsploit / Exploit-DB for additional public exploits
  • Manual verification of weak credentials and misconfigurations
  • Basic post-exploitation (shell interaction, information gathering)

Challenges & Lessons Learned

  • Enumeration quality directly determines exploitation success — rushing leads to missed opportunities.
  • Understanding why an exploit works (root cause) is more valuable than just getting a shell.
  • Clean, reproducible notes and screenshots are essential for professional reporting.
  • Always operate within authorized scope; lab discipline builds good habits for real engagements.
