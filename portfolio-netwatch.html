project_overview.md

Project Overview

NetWatch SOC v2 is a full-spectrum, from-scratch network security monitoring platform built entirely in Python. It provides three complete interface modes — a Rich-powered CLI dashboard, a Flask + SocketIO SIEM web interface, and a Tkinter desktop GUI — all sharing the same detection engine beneath. The system performs real-time packet capture and analysis via Scapy, detects active threats including ARP spoofing, port scans, and DDoS patterns, and classifies anomalous flows using a trained AI/ML ensemble (Isolation Forest + Random Forest) backed by the CIC-IDS2017 dataset. Events are persisted in an SQLite database via SQLAlchemy with a rotating log system for long-term incident retention.

Why I Built This

Commercial SIEM platforms are heavyweight, expensive, and often overkill for small-scale lab or homelab monitoring. NetWatch SOC v2 was designed as a lightweight, self-contained alternative that a cybersecurity professional can deploy instantly — on a laptop, a Raspberry Pi, or a cloud VM — with zero external dependencies beyond a Python environment. It was also a deliberate exercise in building the full detection pipeline end-to-end: from raw packets all the way to ML classification and alert storage.

ml_pipeline.md

AI / ML Detection Pipeline

The ML subsystem uses a two-stage ensemble approach trained on the CIC-IDS2017 benchmark dataset, covering BENIGN, DoS, DDoS, PortScan, Brute Force, and Web Attack traffic categories.

01
Data Preprocessing — CIC-IDS2017
Raw PCAP flows are converted to feature vectors: packet length stats, inter-arrival times, flow duration, byte ratios, flag counts (SYN/FIN/RST), and protocol distribution. StandardScaler normalization applied before inference.
02
Stage 1 — Isolation Forest (Unsupervised)
Isolation Forest scores each flow for anomaly probability without needing labelled data. Novel attack patterns that don't match known categories are flagged here first — provides zero-day detection capability.
03
Stage 2 — Random Forest Classifier (Supervised)
Flows flagged by Isolation Forest (or high packet-rate heuristics) are passed to the Random Forest for precise attack category classification: DoS / DDoS / PortScan / BruteForce / WebAttack / BENIGN.
04
Alert Routing & Storage
Classified threats are written to SQLite via SQLAlchemy with timestamp, source IP, destination IP, protocol, attack type, and confidence score. The rotating log system caps file size while preserving recent history.

detection_capabilities.md

Rule-Based Detection — Threats Covered

  • ARP Spoofing Detection — Monitors ARP request/reply tables for IP-MAC binding conflicts. Alerts when a MAC address claims an IP already mapped to a different MAC. Scapy ARP layer parsing · MAC table tracking · spoofed GW detection
  • Port Scan Detection — Tracks SYN packets per source IP with configurable thresholds. Identifies horizontal (single IP, multiple ports) and vertical (multiple IPs, same port) sweep patterns. SYN flood heuristics · Nmap signature patterns · configurable rate threshold
  • DDoS Alert System — Monitors inbound packet rate and flow entropy. Fires when traffic from a single source exceeds the baseline rate or when destination diversity collapses (volumetric DDoS indicator). PPS rate limiting · flow entropy · UDP/ICMP flood patterns
  • Protocol Analyzer — Deep-parses packets to extract protocol distribution, DNS queries, HTTP hosts, and TCP flag states for session reconstruction. TCP/UDP/ICMP/DNS/HTTP layers · flag state machine
  • Network Topology Mapping — Builds a live network graph using NetworkX, updating node positions as new hosts are discovered from ARP and IP packets. Plotly renders the interactive graph in the Web SIEM. NetworkX graph · Nmap host discovery · Plotly force-directed layout

# Real-time packet capture and ARP spoof detection from scapy.all import sniff, ARP, IP, TCP arp_table = {} # ip → mac mapping def process_packet(pkt): if ARP in pkt and pkt[ARP].op == 2: # ARP reply ip, mac = pkt[ARP].psrc, pkt[ARP].hwsrc if ip in arp_table and arp_table[ip] != mac: alert(f"ARP SPOOF: {ip} claimed by {mac}") arp_table[ip] = mac if TCP in pkt and pkt[TCP].flags == 'S': track_syn(pkt[IP].src) # feed port scan detector sniff(iface="eth0", prn=process_packet, store=False)
