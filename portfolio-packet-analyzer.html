Project Overview

Developed a Python-based Network Packet Analyzer that captures and analyzes live network traffic using Scapy. The tool helps in identifying protocol types, packet metadata, and network behaviour for security analysis and monitoring.

Key Features

✅ Live packet sniffing
✅ Protocol identification (TCP/UDP/ICMP etc.)
✅ Source/Destination IP and Port analysis
✅ Output formatting for investigation and logging
